# 아이템별 재고 종합분석 (최근 12개월)

• 조기경보 대상 아이템 없음
• 개별 아이템별 재고 증가 데이터 부재
• 전체 재고는 2025년 10월 635,076백만원 최고점 기록

## 긍정신호

• 긍정신호 대상 아이템 없음
